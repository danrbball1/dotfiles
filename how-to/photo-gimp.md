
## Straighten Photo
To straighten a photo in GIMP, use the Measure Tool (shortcut Shift+M) to draw a line along a feature that should be horizontal or vertical.  Once the line is drawn, click the Straighten button in the tool options dialog to automatically rotate the image to the correct angle. 

For more manual control or to correct perspective distortion, use the Rotate Tool (Shift+R) with the Clipping option set to Crop with Aspect or Crop to Content.  Align the grid manually to a reference line, apply the rotation, and then use Image > Crop to Content to remove the empty corners.  For documents scanned at an angle, the Unified Transform Tool (Shift+T) or the Deskew plugin can also be used to straighten and crop the image in one step.
